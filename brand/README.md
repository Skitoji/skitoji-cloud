# Skitoji — Flujo / kit para redes

[Descargar el ZIP completo](skitoji-flujo-kit.zip).

42 gráficos: SVG/PDF, PNG transparentes 128–4096 px y avatares en fondos claro/oscuro/azul 400–2048 px. Incluye JPG de 1080 px, guía de uso y manifest. Todos derivan del mismo vector final.

![Variantes de perfil](skitoji-flujo-preview.png)

Para perfiles, comenzar con el PNG de 1080 px y revisar el recorte que muestra cada red. Para colocar el logo sobre fotografía o video, usar PNG transparente. Para animación, impresión y otros tamaños, usar SVG/PDF. No deformar ni recortar los extremos del símbolo.
